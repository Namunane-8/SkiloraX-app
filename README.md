# SkiloraX — Show Your Skills. Get Discovered.

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2FNamunane-8%2Fskilorax-app)

**Built in Africa. Designed for the World.**

SkiloraX is a professional social platform where users showcase skills, discover opportunities, and connect with professionals worldwide.

## Features

### Core Features
- **Professional Identity** – Create a rich profile with skills, portfolio, and achievements
- **Sparks** – Share text, images, videos, projects, polls, and questions
- **Social Feed** – Like, comment, reshare, quote, and save content
- **Expert Marketplace** – Discover and book sessions with verified experts
- **SkiloraXBot AI** – AI-powered caption, skill, hashtag, and opportunity suggestions
- **Messaging** – Real-time chat between users
- **Marketplace** – Buy and sell digital products, services, and courses
- **Opportunities** – Find jobs, freelance work, and collaborations
- **Communities** – Join professional groups and skill-based communities

## Tech Stack

### Frontend
- HTML5, CSS3, JavaScript (ES6+)
- Font Awesome Icons
- Google Fonts (Inter)

### Backend
- Supabase (PostgreSQL + Auth + Storage + Realtime)
- Redis (Caching)
- Meilisearch (Search)

### Infrastructure
- Vercel (Hosting)
- Cloudflare CDN (Media Delivery)
- GitHub (Version Control)
